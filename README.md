# Neurones en forme

Petits jeux d'entraînement cérébral, pour usage personnel : mémoire, attention, vitesse, raisonnement et calcul.

L'appli tient dans `index.html` et fonctionne sur Mac, iPad et iPhone (à ajouter au Dock ou à l'écran d'accueil depuis Safari). Elle reste utilisable sans Internet une fois ouverte une première fois.

Les scores sont gardés sur chaque appareil. Pour les partager entre appareils, on colle dans l'appli un code GitHub avec le seul droit « gist » : les scores vont alors dans un gist privé `neurones-scores.json` du compte.
